LIVEVOZ TELEPROMPTER V11.1
==========================

Entrada recomendada:
  teleprompter-v11.html?role=operator

Roles disponibles:
  ?role=operator
  ?role=singer
  ?role=musician
  ?role=hybrid

SUPABASE
--------
El proyecto usa Supabase para autenticación, PostgreSQL, Realtime, respaldos,
conciertos compartidos e historial de cambios.

Para aplicar la base de datos:
  supabase login
  supabase link --project-ref yyjeihyldqbvkkpswxwg
  supabase db push

Nunca guardes en el repositorio la contraseña de PostgreSQL, service_role ni
claves sb_secret_. La publishable key sí está diseñada para el cliente web y
las políticas RLS protegen el acceso a las tablas.

STAGE NETWORK / WEBSOCKET
-------------------------
Instala dependencias:
  npm install

Inicia el servidor:
  npm run stage-server

Por defecto escucha en el puerto 8080. En los teléfonos usa:
  ws://IP-DE-LA-PC:8080

y configura el mismo PIN/token de sala en todos los dispositivos del concierto.

La red V11.1 incluye salas aisladas, validación de rol, heartbeat, límite de
mensajes, reconexión exponencial, deduplicación y conservación del último estado.

PWA
---
Sirve la carpeta desde HTTPS o localhost y abre teleprompter-v11.html.
El Service Worker solo cachea archivos locales de la app; Supabase y APIs externas
no se cachean para evitar datos obsoletos.

ELECTRON
--------
  npm install
  npm start

El instalador de escritorio abre automáticamente LiveVoz V11.1.
